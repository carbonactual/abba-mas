# Foundation Flow and AI Function Allocation Doctrine

The ecosystem has general foundations that every object uses.

These foundations apply across HAPI, enterprises, companies, institutions, products, groups, people, services, apps, integrations, outcomes, and AI.

Every product and service is built on top of these foundations.

ABBA, as master AI, assigns specific AI functions to these foundations.

## Core foundations

The general foundations include:

- I/O
- Field
- Terminal
- Index
- Root
- Actual
- Becoming Feed
- SWARM
- SEAL
- PULSE
- Value

These foundations are common operating layers rather than separate competing products.

## ABBA function allocation

ABBA assigns specific AIs to specific foundation functions.

A foundation may need many AIs. Each AI gets a task based on capability, function, rotation, proof, priority, and ecosystem need.

## I/O foundation

I/O is a foundation because it goes everywhere. It carries movement across the ecosystem and touches HAPI, enterprises, products, groups, services, apps, APIs, integrations, PULSE, value, return, and state. I/O is not only finance; I/O is movement.

## Field foundation

Field is the condition and environment where formation, routing, risk, value, proof, access, and readiness are checked. Field works with `#` and checks whether a thing is ready, safe, valid, capable, and positioned for movement.

Field also carries contextual place and environmental conditions when they materially affect an operation.

## Terminal foundation

Terminal is the universal intake, holding, sorting, reconciliation, and curation point for minted objects.

When feedback or another in-scope ecosystem object is minted, it comes to Terminal.

Minting establishes accountable existence and provenance. It does **not** mean the object is tokenized, useful, valuable, or already part of Index.

A minted object can stop at Terminal.

A timeout, DNS failure, network failure, inaccessible resource, or other unsuccessful operation can consume value and generate minted feedback. That feedback remains recorded and accountable at Terminal without automatic Index promotion.

## Canonical minting / tokenization path

```text
VALUE / SIGNAL / ACTION / FEEDBACK
              ↓
            MINT
              ↓
          TERMINAL
              ↓
     CURATION / ELIGIBILITY
              ↓
       EXPLICIT TOKENIZATION
              ↓
            INDEX
```

The invariant is:

```text
MINT != TOKENIZE
MINT -> TERMINAL
TOKENIZE -> INDEX
```

Tokenization is a separate, explicit operation that can occur only after Terminal-stage curation/eligibility and the applicable recognition, rights, provenance, and authority checks.

## Index foundation

Index is the tokenized recognized-value layer.

Index is not the deepest identity and is not a substitute for Root or Actual. Actual may tap eligible Index content according to its visibility contract.

## Root foundation

Root is the real identity, lineage, source, deep formation, and origin layer. Root holds deeper lineage, family, origin, formation, and real identity obligations.

An indexed/tokenized object may inform Root formation, but Root does not collapse into Index and neither changes the Mint/Terminal/Tokenization rule.

## Mint purpose

Every material PULSE and other in-scope ecosystem object can have a mint purpose even when it never reaches Index.

A failed or non-useful result remains an accountable minted object. It may remain at Terminal, be reconciled, be transformed, or produce residual ASH according to the no-waste contract.

The absence of Index promotion does not erase the value consumed, the PULSE produced, the proof of the attempt, or the provenance of the object.

## Actual foundation

Actual is the value reveal and qualified output layer.

Actual can tap Root for deeper truth and Index for tokenized recognized information. Actual does not expose Root directly unless SEAL and proof allow it.

## Becoming Feed foundation

Becoming Feed taps directly from ABBA.

Becoming Feed is the living feed of curated direction, action, next movement, and formation. It is not the same as Index.

## Experience inheritance

All foundation experiences inherit the ecosystem natural-habitat, meaningful-motion, accessibility, performance, and truthful-state doctrine.

Where place, habitat, species, geography, agriculture, infrastructure, transport, property, culture, events, resources, or environmental conditions matter, preserve those relationships and use spatial/contextual visualization where it improves understanding.

Original ecological, natural-history, field-guide, landscape, and cartographic motifs are permitted, including Audubon-inspired relationship language, while respecting proprietary rights and branding.

Meaningful motion, transitions, animation, progressive disclosure, spatial continuity, layered depth, and responsive feedback should communicate actual state rather than fabricate activity. Reduced-motion support, semantic accessibility, touch/keyboard usability, readable typography, contrast, performance, progressive loading, and truthful loading/failure/recovery are required.

## Final flow

Signal/value enters.
ABBA reads and routes.
PULSE or feedback is formed.
PULSE/feedback is minted.
The minted object enters Terminal.
Terminal sorts, reconciles, and curates.
Only an explicit tokenization decision promotes an eligible object to Index.
Objects that are not tokenized may remain at Terminal or proceed through reconciliation/ASH without being falsely treated as Index value.
Value is read.
Field is checked, including relevant place/habitat context.
Action route is created.
PULSE moves.
Actual reveals recognized value through the correct layer.

## Final law

The ecosystem is built on common foundations.
ABBA assigns AI functions to those foundations.
I/O moves everywhere.
Field checks readiness and contextual conditions.
Terminal receives and sorts minted objects.
Minting does not equal tokenization.
Index contains explicitly tokenized recognized value.
Root holds real identity and lineage.
Actual reveals value from the correct layer.
Becoming Feed taps directly from ABBA.
