# Ecosystem Conformance Boundary V1

ABBA MAS is an ABBA capability/orchestration subsystem.

It may contain agent teams, specialist workers, routing, memory, tool bindings and execution patterns, but it is not a second master intelligence or constitutional authority.

## Rules
- Consume OMNII universal contracts.
- Consume ABBA authority/orchestration policy.
- Treat providers and models as replaceable capabilities.
- Preserve provenance, proof, idempotency and bounded authority.
- Never manufacture SEAL or human consent.
- Never create competing identity, value, event or capability primitives.

`MAS ⊂ ABBA capability fabric ⊂ OMNII runtime contracts`
